# 🚀 Omegooo - Anonymous Video & Text Chat Application

Omegooo is a fast, high-performance anonymous video and text chat web application built with Node.js, Express, Socket.IO, WebRTC, and Tailwind CSS.

## ✨ Key Features
- 🎥 **Real-time WebRTC Video Chat**: High-quality peer-to-peer video & audio streaming.
- 💬 **Instant Text Chat**: Low-latency messaging with Socket.IO.
- 🎯 **Interest Matching**: Connect with strangers sharing similar interests.
- 🔒 **VIP Gender Filter**: Unlocked via **Plisio.net** cryptocurrency payments.
- 🛡️ **Safety & Security**: Automatic profanity filtering, IP rate limiting, report system, and admin panel.
- ⚡ **Cloudflare Ready**: Built-in support for Cloudflare Tunnels, `CF-Connecting-IP`, Docker, and WebSocket proxies.

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start the server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
